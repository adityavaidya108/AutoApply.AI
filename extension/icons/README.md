# Extension Icons

Place your extension icons here:
- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Icon Creation:

You can create simple icons using:
1. Any image editor (Photoshop, GIMP, Canva)
2. Online tools like https://www.favicon-generator.org/
3. Or use a simple colored square for testing

For now, the extension will work without icons (Chrome will show a default icon).
